# 🎨 Pro Color Studio 2026

A modern, interactive web-based **Color Picker & Library** designed for developers and designers. Choose custom colors or browse a curated library of high-contrast professional palettes.

## 🚀 Features

* **Interactive Color Picker:** Select any custom color using the native system picker.
* **Curated Color Library:** Includes 50+ professional colors with unique names (including *Cherry Blossom*, *Deep Space Blue*, and *Electric Rose*).
* **Instant Conversion:** Real-time display of both **HEX** and **RGB** values.
* **One-Click Copy:** Quickly copy HEX codes to your clipboard for use in your CSS/HTML.
* **Dark Mode Ready:** Optimized interface with a sleek dark background for professional coding environments.

## 📂 Project Structure

The project is built using a clean separation of concerns:

* `index.html` - The structural backbone of the application.
* `style.css` - Custom modern styling and scrollable layouts.
* `script.js` - Dynamic logic, clipboard management, and the color database.

## 🛠️ Installation & Usage

1.  **Clone or Download** the repository to your local machine.
2.  Ensure all three files (`index.html`, `style.css`, `script.js`) are in the **same folder**.
3.  Open `index.html` in any modern web browser (Chrome, Firefox, Edge, or Safari).
4.  Click on any color in the library to select it, or use the circular picker for a custom choice.
5.  Press **"Copy HEX"** to save the color to your clipboard.
