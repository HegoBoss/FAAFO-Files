# 📄 Simple Web PDF Reader

A lightweight, web-based PDF viewer built with **HTML5**, **CSS3**, **JavaScript**, and Mozilla's **PDF.js** library. This tool allows you to view PDF files directly in your browser without needing external software.

## 🚀 Features
* **File Selection:** Upload and view local PDF files.
* **Navigation:** Easily flip through pages with 'Previous' and 'Next' buttons.
* **Page Indicator:** Real-time display of current page and total page count.
* **Responsive Canvas:** The PDF is rendered cleanly on an HTML5 Canvas element.

## 📁 Project Structure
* `index.html`: The structural layout.
* `style.css`: Modern and clean styling.
* `script.js`: Logic for loading and rendering the PDF using PDF.js.

## 🛠️ Setup & Usage

1.  **Download files:** Ensure `index.html`, `style.css`, and `script.js` are in the same folder.
2.  **Open the app:** Open `index.html` in any modern web browser.
3.  **View a PDF:** Click "Choose File," select a PDF from your computer, and start reading!
